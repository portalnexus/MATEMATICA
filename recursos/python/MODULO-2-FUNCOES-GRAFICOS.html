Funções, Álgebra & Visualização: Do Teorema de Bolzano ao Gráfico

Neste módulo, aprenderemos a modelar funções matemáticas em Python, encontrar raízes analíticas e numéricas e transformar tabelas de dados em gráficos cartesianos de alta definição com Matplotlib.

1. Funções Matemáticas como Objetos de Primeira Classe

Em Python, uma função matemática @f: \mathbb{R} \to \mathbb{R}@ é implementada com a palavra-chave def ou com funções anônimas lambda: 

# Definindo a função f(x) = 2x³ - 5x + 3
def f(x):
    return 2 * x**3 - 5 * x + 3

# Avaliando f em diferentes pontos
pontos_x = [-2, -1, 0, 1, 2]
print({x: f(x) for x in pontos_x})

2. Raízes Numéricas: O Método da Bisseção

Teorema: Teorema do Valor Intermediário (Bolzano)

Seja @f: [a, b] \to \mathbb{R}@ uma função contínua. Se @f(a) \cdot f(b) < 0@ (isto é, @f(a)@ e @f(b)@ têm sinais opostos), então existe pelo menos um @c \in (a, b)@ tal que @f(c) = 0@.

Exemplo Prático: Implementação da Bisseção

Dividimos o intervalo ao meio repetidamente até alcançar a tolerância desejada (@\varepsilon = 10^{-6}@):

def bissecao(f, a, b, tol=1e-6, max_iter=100):
    if f(a) * f(b) >= 0:
        raise ValueError("f(a) e f(b) devem ter sinais opostos!")
        
    for i in range(max_iter):
        m = (a + b) / 2
        if abs(f(m)) < tol or (b - a) / 2 < tol:
            print(f"Convergência em {i+1} iterações!")
            return m
        if f(a) * f(m) < 0:
            b = m
        else:
            a = m
    return (a + b) / 2

# Encontrando a raiz de x³ - x - 2 = 0 no intervalo [1, 2]
raiz = bissecao(lambda x: x**3 - x - 2, 1, 2)
print(f"Raiz aproximada: {raiz:.6f}")

3. Plotagem Gráfica de Curvas com Matplotlib

Visualizar o comportamento global de funções afins, quadráticas e trigonométricas é essencial para a intuição matemática. Veja como plotar uma parábola completa com seu vértice em destaque: 

import matplotlib.pyplot as plt
import numpy as np

# Gerar 400 pontos de x entre -4 e 4
x = np.linspace(-4, 4, 400)
y = x**2 - 2*x - 3  # f(x) = x² - 2x - 3

plt.figure(figsize=(8, 5))
plt.plot(x, y, label='f(x) = x² - 2x - 3', color='#38bdf8', linewidth=2)
plt.axhline(0, color='white', linestyle='--', alpha=0.4)
plt.axvline(0, color='white', linestyle='--', alpha=0.4)

# Destacar o vértice V(1, -4)
plt.scatter([1], [-4], color='#f43f5e', zorder=5, label='Vértice (1, -4)')

plt.title('Estudo Gráfico da Função Quadrática')
plt.xlabel('Eixo x')
plt.ylabel('Eixo y')
plt.grid(True, alpha=0.2)
plt.legend()
plt.show()
