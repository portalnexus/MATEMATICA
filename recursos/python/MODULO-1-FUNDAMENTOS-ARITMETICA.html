MÓDULO COMPUTACIONAL 01

Python & Teoria dos Números: Aritmética Exata e Algoritmos Clássicos

Neste módulo, exploramos a ponte entre as propriedades fundamentais dos números inteiros (@\mathbb{Z}@) e a arquitetura do Python, aprendendo como o computador manipula inteiros de precisão arbitrária e implementando dois pilares milenares da computação: o Algoritmo de Euclides e o Crivo de Eratóstenes.

1. Inteiros de Precisão Arbitrária no Python

Definição: Aritmética de Precisão Arbitrária (Bignum)

Diferente de linguagens como C ou Java, onde números inteiros normalmente sofrem overflow ao ultrapassarem 32 ou 64 bits (@2^{63} - 1 \approx 9,22 \times 10^{18}@), o tipo int em Python possui precisão arbitrária. Seu limite é unicamente a memória RAM disponível do dispositivo.

Isso permite calcular valores gigantescos, como fatoriais e potências astronômicas, sem perder um único dígito de precisão:

# Cálculo de 100! (fatorial de 100) com precisão absoluta
import math

n = 100
fatorial_100 = math.factorial(n)
print(f"100! possui {len(str(fatorial_100))} dígitos decimais!")
print("Primeiros 50 dígitos:", str(fatorial_100)[:50] + "...")

2. Divisão Euclidiana: Quociente (@//@) e Resto (@\%@)

Teorema: Teorema da Divisão Euclidiana

Dados dois inteiros @a@ e @b@, com @b > 0@, existem únicos inteiros @q@ (quociente) e @r@ (resto) tais que:

@@ a = b \cdot q + r, \quad \text{onde } 0 \le r < b @@

Em Python, obtemos diretamente @q = a // b@ e @r = a \% b@, ou simultaneamente com divmod(a, b):

a, b = 57, 7
q = a // b   # 8
r = a % b    # 1

print(f"{a} = {b} * {q} + {r}")  # 57 = 7 * 8 + 1

3. O Algoritmo de Euclides para o MDC

Lema de Euclides

Se @a = b \cdot q + r@, então @\operatorname{mdc}(a, b) = \operatorname{mdc}(b, r)@. Repetindo sucessivamente as divisões com os restos, chegamos ao último resto não nulo, que é o MDC!

Exemplo Passo a Passo: Algoritmo de Euclides em Python

Implementamos uma versão interativa que exibe a tabela de divisões sucessivas:

def mdc_euclides(a, b):
    """Calcula o MDC(a, b) com rastreamento das divisões."""
    passo = 1
    while b != 0:
        q = a // b
        r = a % b
        print(f"Passo {passo}: {a} = {b} * {q} + {r}")
        a, b = b, r
        passo += 1
    return a

resultado = mdc_euclides(1071, 462)
print(f"\nO MDC é: {resultado}")  # Resultado: 21

4. O Crivo de Eratóstenes

Para encontrar todos os números primos até um limite @N@, o método mais eficiente é marcar iterativamente os múltiplos de cada primo identificado. Sua complexidade temporal é @O(N \log \log N)@. 

def crivo(limite):
    eh_primo = [True] * (limite + 1)
    eh_primo[0] = eh_primo[1] = False
    
    for p in range(2, int(limite**0.5) + 1):
        if eh_primo[p]:
            for multiplo in range(p * p, limite + 1, p):
                eh_primo[multiplo] = False
                
    return [i for i, primo in enumerate(eh_primo) if primo]

primos_ate_200 = crivo(200)
print(f"Existem {len(primos_ate_200)} primos até 200:")
print(primos_ate_200)
