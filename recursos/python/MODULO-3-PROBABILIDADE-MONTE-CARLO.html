Probabilidade Experimental & O Método de Monte Carlo

Quando um problema probabilístico é excessivamente complexo para resolver analiticamente no papel, os matemáticos recorrem a Simulações de Monte Carlo: realizamos milhões de experimentos aleatórios virtuais para obter respostas com extrema acurácia.

1. A Lei dos Grandes Números

Teorema: Lei Fraca dos Grandes Números (Khinchin)

À medida que o número de repetições @n@ de um experimento aleatório cresce (@n \to \infty@), a média observada @\bar{X}_n@ converge em probabilidade para o valor esperado teórico @\mu = E[X]@:

@@ \lim_{n \to \infty} P(|\bar{X}_n - \mu| \ge \varepsilon) = 0, \quad \forall \varepsilon > 0 @@

Veja a simulação do lançamento de uma moeda honesta (@P(\text{Cara}) = 0{,}5@):

import random

def simular_lancamentos(n):
    caras = 0
    for _ in range(n):
        if random.random() < 0.5:
            caras += 1
    frequencia = caras / n
    print(f"Lançamentos: {n:>7} | Caras: {caras:>6} | Frequência: {frequencia:.4f}")

for n in [10, 100, 1000, 10000, 100000]:
    simular_lancamentos(n)

2. Estimando o Número @\pi@ com Dardos Aleatórios

Fundamentação Geométrica

Considere um quarto de círculo de raio @r = 1@ inscrito em um quadrado de lado @1@.
Área do quarto de círculo: @A_{\text{setor}} = \frac{\pi r^2}{4} = \frac{\pi}{4}@
Área do quadrado unitário: @A_{\text{quadrado}} = 1 \times 1 = 1@
A probabilidade de um ponto aleatório @(x, y) \in [0, 1] \times [0, 1]@ cair dentro do círculo (@x^2 + y^2 \le 1@) é:

@@ P(\text{dentro}) = \frac{A_{\text{setor}}}{A_{\text{quadrado}}} = \frac{\pi}{4} \implies \pi = 4 \cdot P(\text{dentro}) @@

Simulação de Monte Carlo Completa

import random
import math

def monte_carlo_pi(pontos):
    dentro = 0
    for _ in range(pontos):
        x = random.uniform(0, 1)
        y = random.uniform(0, 1)
        if x**2 + y**2 <= 1.0:
            dentro += 1
            
    pi_aprox = 4 * (dentro / pontos)
    erro = abs(pi_aprox - math.pi) / math.pi * 100
    print(f"Pontos: {pontos:,} | Pi estimado: {pi_aprox:.5f} | Erro: {erro:.3f}%")

monte_carlo_pi(500_000)

3. Resolvendo o Paradoxo de Monty Hall

O Dilema das Três Portas

Em um programa de TV, existem 3 portas: atrás de uma há um carro esportivo, e atrás das outras duas, cabras. Você escolhe uma porta. O apresentador (que sabe o que há atrás de cada uma) abre uma das outras duas portas revelando uma cabra e pergunta: "Você deseja trocar de porta?"
Vale a pena trocar? Sim! Trocar dobra sua chance de vitória (@\frac{2}{3}@ vs @\frac{1}{3}@). 

def teste_monty_hall(n_jogos=50000):
    sem_troca = 0
    com_troca = 0
    
    for _ in range(n_jogos):
        portas = [0, 1, 2]
        premio = random.randint(0, 2)
        escolha = random.randint(0, 2)
        
        # Apresentador revela uma cabra que não foi a escolha
        aberta = [p for p in portas if p != escolha and p != premio][0]
        troca = [p for p in portas if p != escolha and p != aberta][0]
        
        if escolha == premio:
            sem_troca += 1
        if troca == premio:
            com_troca += 1
            
    print(f"Vitórias Mantendo a Porta: {sem_troca/n_jogos*100:.2f}% (Teórico: 33.3%)")
    print(f"Vitórias Trocando a Porta:  {com_troca/n_jogos*100:.2f}% (Teórico: 66.7%)")

teste_monty_hall()
